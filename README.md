# AhmadVid

واجهة أولية لتطبيق فيديو عربي حديث باسم **AhmadVid**، مبنية باستخدام React وVite.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهره Vite في المتصفح.

## المميزات الحالية

- واجهة عربية متجاوبة للهاتف والكمبيوتر.
- بحث مباشر وتصنيفات للفيديوهات.
- وضع ليلي ونهاري.
- صفحة مشاهدة تفاعلية لكل فيديو.
- قائمة جانبية، فيديوهات مقترحة، وبانر لصناع المحتوى.
- بيانات تجريبية جاهزة لاستبدالها لاحقاً بواجهة API وقاعدة بيانات.

> هذه نسخة واجهة تجريبية (MVP). رفع الفيديوهات، الحسابات، والتعليقات تحتاج إلى ربط backend لاحقاً.
